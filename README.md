# Dual Screen Wallpaper Tool

This is an Android wallpaper editor made for dual-screen devices like the Ayaneo Pocket DS and Ayn Thor. It lets you load an image, preview it across the top and bottom screens, adjust the framing, fill any black bars and export a wallpaper that matches the dual-screen layout. 

## Features

Dual-screen preview

Live preview of how your wallpaper will look across the top and bottom screens.

Blur Extend (fills missing space using a blurred extension)

Content Aware Fill (simple) (attempts a more “natural” extension)

Adjust framing so the important part of the image sits where you want it.

Export-ready output

Generates an image to set on the top screen and then the bottom screen.



Storage permission may be required depending on your device + Android version (to save/export wallpapers).
